# Criminal Empire System

Organize and manage criminal empires in your FiveM server with this comprehensive system.

## Features

- Create and manage criminal empires
- Join and leave empires with financial costs
- Visualize empire territories with markers
- Database-backed system for persistent data

## Requirements

- FiveM server with ESX Legacy framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your server's resources folder
3. Add `start criminalempire` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

- Use the `/empire` command to access the empire menu
- Create, join, or leave empires through the menu
- Territory markers will appear on your map

## Configuration

Edit the `config.lua` file to adjust:

- Empire name length requirements
- Creation and join costs
- Marker appearance and colors
